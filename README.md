# 🧠 QuizForge

QuizForge is a free browser-based quiz creator and player.

Create your own quizzes, play them, export them as `.qz` files, import quizzes from other people, and share quizzes with a link.

## ✨ Features

- 📝 Create quizzes
- ❓ Add unlimited questions
- ✅ Four multiple-choice answers
- 🎯 Choose the correct answer
- ▶️ Play quizzes
- 📊 Automatic scoring
- 🏆 Results screen
- 📤 Export `.qz` files
- 📥 Import `.qz` files
- 🔗 Share quizzes using links
- 💾 Save quizzes locally
- 📱 Mobile friendly
- 🌐 Works with GitHub Pages
- 🚫 No server required
